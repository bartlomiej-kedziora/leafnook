# Leafnook Frontend

This module contains the frontend application for **Leafnook**.

## 🧠 Overview

The frontend will be built using:

* Angular (latest stable version)
* Lovable.dev (for UI generation and scaffolding)

## 🎯 Responsibilities

* User interface
* Authentication flows (login, registration, verification)
* Library browsing
* PDF reading experience
* Interaction with backend API

## 🔌 Integration

The frontend communicates with the backend via:

* REST API (`/api/v1/...`)

## 📦 Status

🚧 Not implemented yet – planned after backend MVP

* reader UI (PDF.js integration)
