# Leafnook Infrastructure

This directory contains infrastructure and deployment configuration.

## 🧱 Components

* Docker setup
* Docker Compose configuration
* MinIO (object storage)
* PostgreSQL (database)
* Nginx (reverse proxy)

## 🎯 Purpose

To provide a reproducible environment for:

* local development
* testing
* deployment (including Raspberry Pi)

## 📦 Structure

* `docker/` – container definitions and compose files
* `nginx/` – reverse proxy configuration

## 🚀 Planned Services

* backend (Spring Boot)
* database (PostgreSQL)
* object storage (MinIO)
* frontend (static Angular build served via Nginx)

---

Infrastructure will evolve alongside the application.
